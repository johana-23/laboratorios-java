# Laboratorios Java

Repositorio personal del proceso formativo en Java. Cada laboratorio vive en su propia carpeta y se conserva
intacto cuando se agrega el siguiente, de modo que el historial de commits muestra la evolucion desde la primera
aplicacion de consola hasta la billetera con colecciones.

Aprendiz:Johana Fernandez

## Estado de los laboratorios

| Carpeta | Tema | Estado |
|---|---|---|
| [`laboratorio-1`](laboratorio-1/) | Fundamentos de Java, `Scanner`, operadores y `CotizadorCompra` | Completado |
| [`laboratorio-2`](laboratorio-2/) | Condiciones, ciclos, `switch`, metodos y `BilleteraConsola` | Completado |
| [`laboratorio-3`](laboratorio-3/) | POO: `MiBilleteraJava` (`Main`, `Billetera`, `PruebaBilleteras`) | Completado |
| [`laboratorio-04`](laboratorio-04/) | Colecciones, historial (`Movimiento`), reportes y excepciones | Completado |

## Instrucciones de ejecucion

Requisito: JDK 21 o superior (`javac -version`).

laboratorio-1: `cd laboratorio-1` -> `javac CotizadorCompra.java` -> `java CotizadorCompra`

laboratorio-2: `cd laboratorio-2/metodos-billetera-consola` -> `javac -encoding UTF-8 BilleteraConsola.java` -> `java BilleteraConsola`

laboratorio-3: `cd laboratorio-3/MiBilleteraJava` -> `javac -encoding UTF-8 *.java` -> `java Main`

laboratorio-4: `cd laboratorio-04/MiBilleteraJava` -> `javac -encoding UTF-8 *.java` -> `java Main`

Cada carpeta tiene su propio `README.md` con el detalle del laboratorio.
